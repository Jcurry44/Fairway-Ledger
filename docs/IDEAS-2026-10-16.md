# Fairway Ledger — ideas to make it worth opening again (2026-10-16)

Joe's ask: easier logging that still gives good analytics, better UI/UX, and fun
that brings him back. 17 ideas were drafted, a Fable review kept 11, cut 3, deferred 2,
added 2. Ranked by delight × logging ease × analytics ÷ effort.

## Wave 1 build notes
- Quick is the default only when Profile never chose a mode; explicit Detailed/Speed are kept.
  The first Quick card has a one-time intro with "Use Detailed instead".
- Known side effect of honest data: FIR% rises wherever fairways were left blank, and speed
  rounds leave putting / GIR / scrambling / tee-club stats. Existing rounds are never rewritten.
- Edge case: switching Quick → Detailed mid-round seeds Detailed's default Driver, which stays
  if you switch back.
